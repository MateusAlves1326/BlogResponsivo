Projeto de exemplo de blog responsivo desenvolvido em HTML e CSS, com foco em técnicas de layout moderno e design adaptável.

 Descrição

Este projeto consiste em um blog fictício, construído com HTML5 e CSS3, cujo objetivo é demonstrar:

Boas práticas de estruturação semântica de HTML

Layouts responsivos utilizando Flexbox, Grid e media queries

Concepção de um site que se adapta bem a diferentes tamanhos de tela (desktop, tablet e mobile)

Facilidade de customização e extensão para projetos reais
